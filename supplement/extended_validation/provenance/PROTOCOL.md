# Alibaba provenance: frozen source-recovery protocol

## Material Passport

Mode: source audit and validated workload extraction. Date: 2026-11-09. User authorized additional experiments; the earlier explicit raw-download exception remains pending separately. No external raw trace has been downloaded at protocol creation.

1. Inspect the preserved archive without executing its scripts. Record original member hashes, graph constants, hard-coded input paths and whether any job identifier/mapping was retained. The presence of an extraction script does not establish a particular job-to-graph mapping.
2. Use the official `cluster-trace-v2018` rule: a task with name `M5_3_4` has identifier 5 and parents 3 and 4; the first letter has no dependency meaning. An opaque `task_*` name is an independent task, not a numeric DAG task. Other unknown names are rejected explicitly. Validate duplicate IDs, missing parents, self-edges, cycles, weak connectivity and single-entry/single-exit status. Record the filtering funnel.
3. Raw input is accepted only from an explicit local path. The parser never downloads data. For the official tarball require SHA-256 `7c4b32361bd1ec2083647a8f52a6854a03bc125ca5c202652316c499fbf978c6`, as documented by Alibaba. Official HEAD on 2026-11-09 reports 130,310,549 bytes. Preserve the archive outside committed evidence.
4. A bounded SQLite aggregation supports non-contiguous job records without assuming sorted input. Identical task names within a job are aggregated, with original record counts. Conflicting numeric identifiers are not merged. The task duration proxy is the arithmetic mean of positive finite `end_time-start_time` spans from its rows, in seconds; this is an observed batch-task wall-span proxy, not CPU service time on either study device. Nonpositive/missing spans exclude an instance from duration-based scheduling but not the topology funnel.
5. Search every valid ten-task job for exact directed unweighted graph isomorphism with the archived ten-task graph. Save matching job IDs and a node mapping. A topology match is only a source candidate: it cannot establish which historical job the authors used or the provenance of the archived numerical constants. Do not present a newly selected trace job as a recovered historical record.
6. For a new trace-based supplementary set, select the lexicographically first ten valid, weakly connected, single-entry/single-exit jobs with valid durations in each frozen size stratum: 8–20, 40–60 and 80–100 tasks. Missing cells are reported. No selection on algorithm performance. Export original names/IDs, spans and mapping. The new edge-server durations use the explicit synthetic speedup 3; cross-resource delays are synthetic at CCR=1, proportional to the mean supplied duration. Label all such assumptions; the trace does not supply communication data volumes.
7. Keep test fixtures separate from trace records. Passing a parser fixture or finding a structural match is not evidence that archived durations are measured. Preserve original paper and datasets; new results are additive.

Sources: https://github.com/alibaba/clusterdata/blob/3858992ca41bf92082e6d6522ddf0bebd14e838b/cluster-trace-v2018/trace_2018.md and `schema.txt` in the same directory. These metadata documents may be read without fetching the raw dataset.
